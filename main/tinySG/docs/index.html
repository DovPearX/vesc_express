Build an indicator from primitives
Application widgets can be composed from arcs, lines, shapes, text and images. This value indicator uses three nodes:
(def value 65)
(def label-text (str-from-n (to-i value) "%d"))
(def label-size (tinysg 'text-size label-text 5 4))
(tinysg 'render 0 (list
  (tinysg 'arc 160 90 70 0x2128 135 270 '(thickness 8))
  (tinysg 'arc 160 90 70 0x05d9 135 (to-i (* value 2.7)) '(thickness 8))
  (tinysg 'text (- 160 (/ (ix label-size 0) 2)) 106 0xffff label-text '(font 5 4))))
